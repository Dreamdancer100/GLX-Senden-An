## ✨ Features

- 🚀 **Right-click to Nextcloud:** Send any image from a web page straight into your own Nextcloud files.
- 🧩 **Your server name in the menu:** The context menu shows the name you choose, e.g. "Send to GLX-Cloud".
- ⚙️ **No download detour:** Pictures go directly to the cloud, not into the local download folder.
- 🔒 **Folder of your choice:** Pick the target folder from a list of your Nextcloud folders.
- 📂 **Creates the folder:** A missing target folder is created automatically.
- ⚡ **Confirmation:** A notification tells you when the image has been saved.
- 🎨 **App password:** Uses a separate Nextcloud app password that you can revoke at any time.
- 🌍 **Export and import:** Take your settings to a new installation or device; the app password only if you choose so.
- 🛠️ **Themes:** Several colour designs.
- 📊 **Built-in help:** Step-by-step guide for setting up the connection.
