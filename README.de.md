## ✨ Funktionen

- 🚀 **Per Rechtsklick in die Nextcloud:** Schick jedes Bild einer Webseite direkt in deine eigenen Nextcloud-Dateien.
- 🧩 **Dein Servername im Menü:** Das Kontextmenü zeigt den Namen, den du wählst, zum Beispiel "Senden an GLX-Cloud".
- ⚙️ **Ohne Umweg über Downloads:** Bilder gehen direkt in die Cloud, nicht in den lokalen Download-Ordner.
- 🔒 **Dein Wunschordner:** Wähle den Zielordner aus der Liste deiner Nextcloud-Ordner.
- 📂 **Ordner anlegen:** Fehlt der Zielordner, wird er automatisch angelegt.
- ⚡ **Bestätigung:** Eine Meldung sagt dir, wenn das Bild gespeichert ist.
- 🎨 **App-Passwort:** Nutzt ein eigenes Nextcloud-App-Passwort, das du jederzeit widerrufen kannst.
- 🌍 **Export und Import:** Nimm deine Einstellungen mit auf eine neue Installation oder ein anderes Gerät, das App-Passwort nur, wenn du willst.
- 🛠️ **Designs:** Mehrere Farbdesigns.
- 📊 **Eingebaute Hilfe:** Schritt-für-Schritt-Anleitung zum Einrichten der Verbindung.
